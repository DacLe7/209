# Post-Apocalyptic Tower/Base Defense

Dự án game thủ thành 2.5D màn hình dọc phong cách hậu tận thế được phát triển bằng Godot Engine.

## Thông tin dự án
- **Engine**: Godot 4.7 (`4.7.1-stable`)
- **Ngôn ngữ**: GDScript
- **Nền tảng mục tiêu**: Android (Google Play)
- **Độ phân giải tham chiếu**: 720 x 1280 (màn hình dọc)

## Hướng dẫn mở và chạy dự án
1. Cài đặt Godot Engine phiên bản 4.7.1-stable.
2. Mở Godot, chọn **Import**, trỏ tới thư mục chứa file `project.godot`.
3. Bấm **Edit** để mở dự án trong Editor.
